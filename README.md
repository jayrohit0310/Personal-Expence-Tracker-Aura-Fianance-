# 💰 Personal Expense Tracker

A modern and user-friendly **Personal Expense Tracker** that helps users manage their daily finances efficiently. Users can record income and expenses, categorize transactions, monitor spending habits, and generate downloadable reports for selected time periods.

---

## 📌 Features

- 🔐 Secure User Authentication
- 💵 Add Income & Expenses
- 📂 Categorize Transactions
- 📅 Filter Expenses by Date
- 📊 Interactive Dashboard
- 📈 Expense Analytics & Charts
- 💳 Track Current Balance
- 📝 Transaction History
- 📥 Download Monthly/Custom Reports
- 🌙 Responsive & Clean UI
- 📱 Mobile Friendly Design

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/personal-expense-tracker.git
```

### Navigate to Project

```bash
cd personal-expense-tracker
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
